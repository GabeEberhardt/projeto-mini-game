# 🎈 Estoura Balões

Mini game feito apenas com **HTML, CSS e JavaScript puro**, sem frameworks ou bibliotecas. Estoure os balões antes que eles escapem pelo topo da tela!

## 🎮 Como jogar

1. Clique em **Começar**.
2. Clique nos balões para estourá-los e ganhar pontos.
3. Cada balão que escapar pelo topo faz você perder um coração (você começa com 3).
4. Quando as vidas acabarem, o jogo termina e mostra sua pontuação e o recorde.

A cada 5 balões estourados, a velocidade aumenta.

## ✨ Funcionalidades

- Balões com cores aleatórias que sobem em velocidades diferentes
- Sistema de pontuação e 3 vidas (corações que "quebram" com animação)
- Dificuldade progressiva
- Recorde da sessão com efeito de explosão de partículas
- Nuvens animadas ao fundo durante o jogo
- Layout responsivo, com imagens de tela diferentes para celular

## 🛠️ Tecnologias

- HTML5
- CSS3 (animações, gradientes, media queries)
- JavaScript (manipulação do DOM, `setInterval`, eventos)
